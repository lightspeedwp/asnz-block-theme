# ASNZ Block Theme — Template Parts Reference

This directory contains reusable template parts for the theme, each designed for a specific layout or content context. Template parts are used in block templates and patterns to provide modular, maintainable site structure.

## Parts List

- **header.html** — Site-wide header, includes navigation, branding, and utility links.
- **footer.html** — Site-wide footer, includes navigation, contact info, partner images, and legal notes.
- **sidebar.html** — Sidebar for page and post layouts, includes widgets or navigation.
- **archive-card.html** — Card layout for archive listings (posts, tours, destinations, etc.).
- **accommodation-card.html** — Card layout for accommodation listings.
- **destination-card.html** — Card layout for destination/region listings.
- **room-card.html** — Card layout for room listings.
- **tour-card.html** — Card layout for tour listings.
- **blog-card.html** — Card layout for blog post listings.

## Usage & Standards

- Template parts are referenced in block templates and patterns for modularity and reuse.
- All markup is block-based and follows accessibility and performance best practices.
- Update this README when new template parts are added or existing ones are changed.
