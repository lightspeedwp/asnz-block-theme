# Section Styles Reference

This README documents all section styles in the `styles` folder. Section styles define layout, color, spacing, and typography for major page regions using theme.json tokens for consistency, accessibility, and performance.

## Section Styles

- **Blog Card Meta Section** (`section-blog-card-meta.json`)

  - For meta info in blog cards; compact spacing, small font, styled post terms links.

- **Breadcrumbs Section** (`section-breadcrumbs.json`)

  - For breadcrumb navigation; primary color text, subtle background, padded and spaced links.

- **Card Content Section** (`section-card-content.json`)

  - For card inner content; padded, with small block gap.

- **Card Image Section** (`section-card-image.json`)

  - For card images; rounded top corners.

- **Card Title Section** (`section-card-title.json`)

  - For card titles; centered, large heading, styled links.

- **Card Section** (`section-card.json`)

  - For card containers; base background, rounded corners, shadow.

- **Fast Facts Section** (`section-fast-facts.json`)

  - For fact highlights; bordered, padded, base background, shadow.

- **Footer Section** (`section-footer.json`)

  - For site footer; primary background, contrast text, padded, styled links and headings.

- **Full Width CTA Section** (`section-full-width-cta.json`)

  - For wide call-to-action; padded, rounded, semi-transparent background.

- **Hero Section** (`section-hero.json`)

  - For hero banners; large heading, base color, styled paragraphs and links.

- **Main Header Section** (`section-main-header.json`)

  - For main header; spaced navigation, styled links.

- **Page Section** (`section-page-section.json`)

  - For general page regions; vertical padding, block gap.

- **Page Section Tertiary** (`section-page-section-tertiary.json`)

  - For alternate page regions; tertiary background, vertical padding.

- **Post Pagination Section** (`section-post-pagination.json`)

  - For post navigation; styled navigation links.

- **Post Tags Section** (`section-post-tags.json`)

  - For post tags; styled paragraphs and terms, colored links.

- **Secondary Sticky Navigation** (`section-secondary-sticky-nav.json`)

  - For sticky in-page nav; base background, block gap, sticky handled by CSS.

- **Top Header Section** (`section-top-header.json`)

  - For top header; primary background, base text, styled links.

- **Tour Description Section** (`section-tour-description.json`)

  - For tour descriptions; vertical padding, bold text.

- **Tour Info Row** (`section-tour-info-row.json`)

  - For info rows; zero vertical margin.

- **Tour Info Section** (`section-tour-info.json`)

  - For tour info; compact spacing, styled post terms and links.

- **Website CTA Section** (`section-website-cta.json`)
  - For website call-to-action; padded, rounded, shadow, styled separators and paragraphs.

## Block Styles

For block-level styles (buttons, read-more, etc.), see [`blocks/README.md`](blocks/README.md).

## Notes

- All section styles use theme.json tokens for scalable, accessible, and maintainable design.
- Update this README when new section styles are added.
