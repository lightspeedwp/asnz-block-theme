# Envira Video Gallery Block

Dynamic WordPress block that displays Envira Video Gallery content from custom fields.

## Fields

- `envira_video` - The Envira Video Gallery ID
- `videos_section_title` - Optional section title (defaults to "Videos" if empty)

## Usage

Add the block to any post or page, and populate the custom fields via SCF (Smart Custom Fields) or ACF (Advanced Custom Fields).
